# MuffMis-Timer
MuffMis is a cozy, pixel-art Pomodoro timer desktop application inspired by my dogs, Muffin and Miso, designed to make focusing feel a little less lonely. Featuring a retro-inspired interface, a warm virtual bedroom, and adorable pixel dogs, MuffMis turns productivity into a more comforting experience.


## ✨ Features

- **Pomodoro Timer:** Manage focused work sessions and breaks.
- **Automatic Session Transitions:** Switch between work and break sessions automatically.
- **Cozy Pixel-Art Interface:** A bedroom-inspired design with a purple, pink, and navy-blue color palette.
- **Animated States:** Different GIF animations for work, break, and idle states.
- **Retro Typography:** Custom pixel-style font for a nostalgic aesthetic.
- **Lightweight Desktop App:** Built with Electron and React for Windows.
- **Compact Window:** A small, frameless interface that stays focused on what matters.


## 🛠️ Tech Stack

- **Electron** — Desktop application framework
- **React** — User interface
- **JavaScript** — Application logic
- **CSS** — Styling and animations
- **Electron Builder** — Windows application packaging


## 🎯 Motivation

I wanted to build a small project that combines my interest in programming with something personal. Muffmis Timer is my way of making productivity a little more enjoyable while learning through hands-on development.
